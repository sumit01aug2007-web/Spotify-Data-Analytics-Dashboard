# Spotify Data Analytics Dashboard

## Project Overview

The Spotify Data Analytics Dashboard is an interactive Power BI project designed to explore and visualize music-related data.

The dashboard provides insights into songs, albums, artists, popularity trends, song duration and explicit content using interactive charts and visualizations.

## Objectives

- Analyse song distribution by album type.
- Compare explicit and non-explicit songs.
- Explore artist performance based on song counts.
- Understand popularity trends over time.
- Visualize music data through an interactive dashboard.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV / Excel Dataset

## Key Dashboard Features

- KPI cards for important music statistics.
- Album type analysis.
- Explicit vs non-explicit song comparison.
- Songs by year.
- Artist-wise song analysis.
- Average popularity by album type.
- Monthly and quarterly popularity trends.

## How to Use

1. Download the Power BI project file.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, locate the source dataset.
4. Explore the dashboard using the available filters and visuals.

## Conclusion

This project demonstrates how Power BI can transform raw music data into meaningful visual insights, making it easier to explore patterns and compare different aspects of music data.
